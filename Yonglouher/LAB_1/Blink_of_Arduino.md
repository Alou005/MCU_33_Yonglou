

# Blink


>Blink (ບລິ້ງ) ໃນ Arduino ແມ່ນ "ໂຄ້ດຕົວຢ່າງພື້ນຖານ" ທີ່ໃຊ້ສັ່ງໃຫ້ຫຼອດໄຟ LED ເທິງບອດ Arduino ກະພິບໂດຍເປັນການເປີດ ແລະ ປິດໄຟສະຫຼັບກັນໄປຕາມເວລາທີ່ກຳນົດ.

>ໃນໂລກຂອງການຂຽນໂປຣແກຣມ, Blink ປຽບເໝືອນຄຳສັ່ງ **"Hello World"** ຂອງການເລີ່ມຕົ້ນຮຽນຮູ້ໄມໂຄຣຄອນໂທຣເລີ (Microcontroller) ເພາະມັນເປັນໂຄ້ດທີ່ງ່າຍທີ່ສຸດໃນການທົດສອບວ່າບອດ Arduino ເຮັດວຽກໄດ້ປົກກະຕິຫຼືບໍ່.


> [!Import] Import
> Contents Arduino

> ນໍາໃຊ້ Arduino UNO ມາເຊັກວ່າໄຟຂຶ້ນບໍໂດຍການທຽບໄຟເຂົ້າ ແລະ ເບີ່ງວ່າ LED ເທີງ Board ມັນກະພິບບໍ

> ຫລັງຂາກນັ້ນນໍາມາຕໍ່ເຂົ້າກັບ Breadboard ແລະ ເອົາ LED ມາຕໍ່ໄຟເຂົ້າຈາກ Arduino UNO

> ຂຽນ ແລະ ອັບໂຫລດ Code ຈາກ Arduino IDE ໃສ່ ແລະ ຈະໄດ້ໄຟກະພິບ
